# EchoMark プライバシーポリシー

最終更新日: 【2026 年 月 日】
運営者: 【氏名または屋号】
連絡先: 【メールアドレス】

## 1. 基本の考え方

EchoMark(以下「本アプリ」)は、アカウントの登録なしで使えるブックマークのアプリです。
保存した内容は利用者の端末の中に保存します。運営者がサーバーで利用者の情報を受け取ったり、保管したりすることはありません。
広告や、利用状況を分析するためのツールは使っていません。
AI は、既定では端末の中で動きます。利用者がクラウドの AI を選んだ用途だけ、その会社へ内容を送ります(3. を参照)。

## 2. 端末の中に保存する情報

- 保存したブックマーク(URL・タイトル・本文・メモ・画像や PDF などのファイル)
- AI が作った要約・タグ・カテゴリ、意味で探すための情報(埋め込み)
- チャットの会話、ポッドキャストの音声、オフラインで読むために保存したページや動画
- 利用者が入れたときは、ブックマークに付けた場所
- 設定と、利用者が入れた API キー

ブックマークや会話を収めるデータベースは、端末の中の鍵で暗号化して保存します。API キーも暗号化して保存します。
要約・タグ付け・意味での検索・チャット・音声の文字起こし・文字の読み取り・読み上げは、既定ではすべて端末の中の AI と機能で行い、
そのために保存した内容を端末の外へ送ることはありません。利用者が設定でクラウドの AI を選び、その会社の API キーを入れた用途だけ、
「3. 端末の外への通信」のとおり内容を送ります。

## 3. 端末の外への通信

本アプリは、利用者が操作したときや、利用者が設定した機能のために、次の通信をします。運営者のサーバーへは送りません。
設定の「オフラインモード」をオンにすると、本アプリは通信しません。

| 通信 | 送り先 | 送る内容 |
| --- | --- | --- |
| 保存したページの本文・画像・字幕・動画の取得、リンク切れの確認、購読の確認 | 利用者が保存・購読したサイト | 通常のページの読み込みと同じ要求 |
| チャットの Web 検索、「Web で確かめる」(利用者が API キーを設定したときだけ) | Brave Search | 検索する言葉 |
| 「資料を探す」 | arXiv・はてなブックマーク・Wikipedia・YouTube | 探すテーマ |
| 場所の画面の地図 | OpenFreeMap | 表示している範囲の地図の要求 |
| AI のモデルのダウンロード | Hugging Face | ダウンロードの要求 |
| クラウドの AI を選んだ用途の処理(タグ付け・要約・要約の翻訳、チャット・使い方の質問・「Web で確かめる」・「資料を探す」の選別・ポッドキャストの台本) | 利用者が選んだ会社: Anthropic(Claude)・Google(Gemini)・OpenAI | タイトル・本文・メモ、チャットの質問と会話、答えに使うブックマークの内容。「ファイルもクラウドで解析」がオンなら、保存した画像・PDF(Gemini には音声・動画も) |
| 音声の文字起こし(上の用途に Gemini か OpenAI を選び、「ファイルもクラウドで解析」がオンのとき) | Google(Gemini)・OpenAI | 保存した音声・動画の音声、音声メモ、チャットの音声入力の声 |
| 検索用の埋め込み(AI の設定で、作る場所を「クラウド」にしたとき) | Google(Gemini)・OpenAI | タイトル・要約・本文、検索する言葉 |

クラウドの AI には、利用者が入れた API キーを使って各社へ直接送ります(運営者のサーバーは通りません)。
送った内容の扱い(保存する期間や、AI の学習に使うかなど)は各社の API の規約とプライバシーポリシーに従い、料金は各社から利用者に請求されます。
何をどの会社へ送るかは、本アプリの AI の設定の画面にも表示します。

それぞれの送り先での情報の扱いは、各サービスのプライバシーポリシーに従います。
このほか、利用者が「ブラウザで開く」などを押したときは、ほかのアプリが通信します。

## 4. 使う権限

| 権限 | 使う所 |
| --- | --- |
| マイク | チャットの音声入力と、音声メモの録音。ボタンを押したときだけ使います。文字起こしは端末の中で行います(クラウドの AI に Gemini か OpenAI を選び、「ファイルもクラウドで解析」がオンのときは、その会社で文字起こしします) |
| おおよその位置情報 | 詳細画面で「現在地を入れる」を押したときに 1 回だけ調べ、そのブックマークに保存します。裏では使いません |
| 通知 | 再発見のお知らせ、処理の進み具合、自動バックアップの失敗のお知らせ |

## 5. 第三者への提供

本アプリは、利用者の情報を第三者に提供・販売しません。運営者が利用者の情報を受け取ることもありません。
利用者がクラウドの AI を選んだときの送信(3.)は、利用者の設定による各社への直接の送信です。

## 6. バックアップ

- 設定の「バックアップを書き出す」で作るファイルは、利用者が選んだ場所に保存します。このファイルは暗号化しないので、
  取り扱いにご注意ください。
- Android の機能で、設定などが利用者の Google アカウントにバックアップされることがあります
  (暗号化したデータベース・保存したファイル・AI のモデルなどは含めません)。

## 7. データの削除

設定の「すべてのデータを削除」で、本アプリが端末に保存したデータを消せます。本アプリをアンインストールしても消えます。
運営者は利用者のデータを預かっていないため、運営者の側で消すものはありません。

## 8. 子どもの利用

本アプリは 13 歳未満の子どもを対象にしていません。
